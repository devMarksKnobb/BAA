# Build Anything (BAA)

ชุดเครื่องมือสร้างซอฟต์แวร์สำหรับ AI Agent ประกอบด้วย MCP server, CLI, การตรวจสอบโปรเจกต์ การสร้าง และการตรวจยืนยัน BAA เป็นเครื่องมือสำหรับนักพัฒนาที่ทำงานในเครื่อง และไม่มีแดชบอร์ด ดูคู่มือฉบับเต็มได้ที่ [README ภาษาอังกฤษ](../../README.md)

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
