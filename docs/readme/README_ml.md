# Build Anything (BAA)

AI ഏജന്റുകൾക്കായുള്ള സോഫ്റ്റ്‌വെയർ നിർമ്മാണ ടൂൾകിറ്റ്. MCP സെർവർ, CLI, പ്രോജക്റ്റ് പരിശോധന, ജനറേഷൻ, വെരിഫിക്കേഷൻ എന്നിവ ഇതിൽ ഉൾപ്പെടുന്നു. BAA പ്രാദേശിക ഡെവലപ്പർ ടൂളാണ്; ഡാഷ്ബോർഡ് ഇല്ല. പൂർണ്ണ ഇൻസ്റ്റാളേഷൻ നിർദ്ദേശങ്ങൾക്ക് [ഇംഗ്ലീഷ് README](../../README.md) കാണുക.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
