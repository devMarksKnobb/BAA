# Build Anything (BAA)

Toolkit per creare software con agenti IA: server MCP, CLI, ispezione dei progetti, generazione e verifica. BAA è uno strumento locale per sviluppatori e non include una dashboard. Consulta il [README in inglese](../../README.md) per le istruzioni complete.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
