# Build Anything (BAA)

AI agents ke liye software bananay ka toolkit: MCP server, CLI, project inspection, generation aur verification workflows. BAA local developer tool hai aur is mein dashboard nahin. Mukammal installation aur MCP setup ke liye [English README](../../README.md) dekhein.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
