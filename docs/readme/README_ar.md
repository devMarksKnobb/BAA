# Build Anything (BAA)

مجموعة أدوات لبناء البرمجيات باستخدام وكلاء الذكاء الاصطناعي، وتتضمن خادم MCP وواجهة CLI وفحص المشاريع والتوليد والتحقق. تعمل BAA محلياً للمطورين ولا تتضمن لوحة تحكم. راجع [ملف README الإنجليزي](../../README.md) للتعليمات الكاملة.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
