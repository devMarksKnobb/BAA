# Build Anything (BAA)

Kit de herramientas para crear software con agentes de IA. Incluye un servidor MCP, CLI, inspección de proyectos, flujos de generación y contratos de verificación. BAA es una herramienta local para desarrolladores; no incluye un panel. Consulta el [README principal en inglés](../../README.md) para la instalación, configuración MCP y desarrollo completos.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
