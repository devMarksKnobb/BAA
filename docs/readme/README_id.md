# Build Anything (BAA)

Perangkat pengembangan perangkat lunak untuk agen AI: server MCP, CLI, pemeriksaan proyek, pembuatan, dan verifikasi. BAA adalah alat pengembang lokal tanpa dashboard. Lihat [README bahasa Inggris](../../README.md) untuk petunjuk instalasi, konfigurasi MCP, dan pengembangan lengkap.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
