# Build Anything (BAA)

Boîte à outils de création logicielle destinée aux agents IA : serveur MCP, CLI, inspection de projets, génération et contrats de vérification. BAA est un outil de développement local, sans tableau de bord. Consultez le [README anglais](../../README.md) pour l’installation complète, la configuration MCP et le développement.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
