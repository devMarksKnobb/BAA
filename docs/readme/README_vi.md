# Build Anything (BAA)

Bộ công cụ phát triển phần mềm dành cho tác nhân AI, gồm máy chủ MCP, CLI, kiểm tra dự án, tạo mã và quy trình xác minh. BAA là công cụ dành cho nhà phát triển chạy cục bộ, không có bảng điều khiển. Xem [README tiếng Anh](../../README.md) để biết hướng dẫn cài đặt, MCP và phát triển đầy đủ.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
