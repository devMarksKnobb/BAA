# Build Anything (BAA)

Yapay zekâ ajanları için yazılım geliştirme araç seti. MCP sunucusu, CLI, proje inceleme, kod üretimi ve doğrulama iş akışları sağlar. BAA yerel bir geliştirici aracıdır; kontrol paneli içermez. Kurulum, MCP yapılandırması ve geliştirme ayrıntıları için [İngilizce README](../../README.md) dosyasına bakın.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
