# Build Anything (BAA)

Kit de ferramentas para criação de software com agentes de IA: servidor MCP, CLI, inspeção de projetos, geração e contratos de verificação. BAA é uma ferramenta local para desenvolvedores e não inclui dashboard. Consulte o [README principal em inglês](../../README.md) para instalação, configuração MCP e desenvolvimento completos.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
