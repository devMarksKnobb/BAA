# Build Anything (BAA)

Набор инструментов для создания программного обеспечения с ИИ-агентами: MCP-сервер, CLI, анализ проектов, генерация и проверка. BAA — локальный инструмент разработчика, без панели управления. Полная инструкция по установке, MCP и разработке доступна в [README на английском](../../README.md).

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
