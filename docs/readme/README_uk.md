# Build Anything (BAA)

Набір інструментів для створення програмного забезпечення за допомогою ШІ-агентів: MCP-сервер, CLI, аналіз проєктів, генерація та перевірка. BAA — локальний інструмент розробника без панелі керування. Повні інструкції з інсталяції, MCP і розробки дивіться в [англомовному README](../../README.md).

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
