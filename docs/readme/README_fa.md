# Build Anything (BAA)

مجموعه ابزار توسعه نرم‌افزار برای عامل‌های هوش مصنوعی؛ شامل سرور MCP، خط فرمان، بررسی پروژه، تولید و راستی‌آزمایی است. BAA ابزار محلی توسعه‌دهندگان است و داشبورد ندارد. برای راهنمای کامل نصب و پیکربندی، [README انگلیسی](../../README.md) را ببینید.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
