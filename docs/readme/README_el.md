# Build Anything (BAA)

Εργαλειοθήκη δημιουργίας λογισμικού για πράκτορες AI: διακομιστής MCP, CLI, επιθεώρηση έργων, δημιουργία και επαλήθευση. Το BAA είναι τοπικό εργαλείο ανάπτυξης χωρίς πίνακα ελέγχου. Δείτε το [README στα Αγγλικά](../../README.md) για πλήρεις οδηγίες.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
