# Build Anything (BAA)

Zestaw narzędzi do tworzenia oprogramowania z agentami AI: serwer MCP, CLI, analiza projektów, generowanie i weryfikacja. BAA to lokalne narzędzie programistyczne bez panelu. Pełne instrukcje instalacji, konfiguracji MCP i pracy nad projektem znajdują się w [angielskim README](../../README.md).

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
