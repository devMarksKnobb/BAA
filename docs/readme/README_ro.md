# Build Anything (BAA)

Set de instrumente pentru dezvoltarea software cu agenți AI: server MCP, CLI, inspectarea proiectelor, generare și verificare. BAA este un instrument local pentru dezvoltatori și nu include un panou de control. Consultă [README-ul în engleză](../../README.md) pentru instrucțiunile complete.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
