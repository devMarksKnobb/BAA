# Build Anything (BAA)

Ein Software-Baukasten für KI-Agenten mit MCP-Server, CLI, Projektanalyse, Generierungsabläufen und Verifikationsverträgen. BAA ist ein lokales Entwicklertool und enthält kein Dashboard. Die vollständige Installation, MCP-Konfiguration und Entwicklung sind in der [englischen README](../../README.md) beschrieben.

```bash
npm ci
npm run build:cached
node scripts/baa.mjs mcp
```
