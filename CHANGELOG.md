# Changelog

All notable changes to Build Anything (BAA) are documented here.

## [1.0.0] - 2026-11-02

### Added

- Established BAA as the sole product identity, npm package, CLI and MCP server.
- Added project analysis, starter generation and structural verification commands.
- Added four BAA project MCP tools and twelve starter targets.
- Added BAA agent workflow guidance and localized README introductions.

### Changed

- Reworked the original modular MCP/CLI codebase into the BAA product surface.
- Updated package, plugin, registry, installer and documentation metadata for BAA.
- Removed the old product logo and added BAA plugin artwork.

### Notes

- Generated target projects are starter scaffolds, not production-complete applications.
- Structural verification does not compile, run, accessibility-test or visually compare projects.
